## این ریپو چیست؟

یک خط تولیدِ کاملاً خودکار (GitHub Actions) که با گرفتنِ **فقط اسمِ کتاب و
کلید API**:

1. زبانِ کتاب را خودکار تشخیص می‌دهد (فارسی یا انگلیسی)
2. متنِ کاملِ کتاب را از منابعِ آزاد پیدا می‌کند (گوتنبرگ، آرشیو اینترنت، وب)
3. در صورت نیاز، ترجمه‌ی تازه‌ی فارسی با Gemini می‌سازد
4. متن را به بخش‌های تصویری تقسیم می‌کند (هر ۶ تا ۱۱ صفحه یک تصویر)
5. برای هر بخش پرامپت تصویری می‌نویسد و تصویرسازی می‌کند
6. یک **PDF حرفه‌ای** با جلد، فهرست، سرصفحه، فوترِ برندشده، شماره‌ی صفحه،
   متادیتا و فهرستِ کنارِ PDF (bookmark) می‌سازد

## راه‌اندازی (سه قدم)

1. این ریپو را Fork/Clone کنید.
2. یک کلید API از [Google AI Studio](https://aistudio.google.com) بگیرید و
   (پیشنهادی و امن‌تر) آن را به‌صورت Repository Secret با نام
   `GEMINI_API_KEY` ذخیره کنید: `Settings → Secrets and variables → Actions`.
3. به تب **Actions** بروید → ورک‌فلوی **📖 Build Book** → **Run workflow** →
   نام کتاب را وارد کنید و اجرا کنید.

بعد از پایان، PDF در بخش **Artifacts** همان اجرا قابل دانلود است.

| ورودی | اجباری | توضیح |
|---|---|---|
| `book_name` | ✅ | نام کتاب، به هر زبانی (فارسی یا انگلیسی) |
| `gemini_api_key` | — | اگر خالی بماند از سکرت `GEMINI_API_KEY` خوانده می‌شود |

زبانِ خروجی خودکار است: کتاب به همان زبانی ساخته می‌شود که متنش پیدا شده
است — نامِ فارسی → کتاب فارسی، نامِ انگلیسی → کتاب انگلیسی. اگر متنِ پیدا‌شده
فارسی نباشد و خروجیِ فارسی خواسته شده باشد (اجرای محلی با `--lang fa`)،
ترجمه‌ی تازه با Gemini ساخته می‌شود.

## اجرای محلی (اختیاری)

```bash
pip install -r scripts/requirements.txt
playwright install chromium

export GEMINI_API_KEY="کلیدِ شما"
python scripts/generate_book.py --title "شازده کوچولو"
```

`--lang` اختیاری است (`auto` پیش‌فرض، یا `fa`/`en` برای اجبار). خروجی در
`output/<slug>-<lang>.pdf` ذخیره می‌شود و گزارشِ ساخت (تعداد صفحه، بخش،
تصویر، منبعِ متن) در `_build/<slug>/layout.json` می‌ماند.

## متن دلخواه خودتان

اگر می‌خواهید متنِ مشخصی مبنای کتاب باشد، کافی‌ست فایل آن را این‌جا قرار دهید
و دوباره اجرا کنید — پردازش (تحلیل، تصویرسازی، PDF) از همان‌جا با همان متن
ادامه پیدا می‌کند:

```
manuscripts/<اسم-کتاب-به-انگلیسی-با-خط-تیره>-fa.txt   # نسخه‌ی فارسی
manuscripts/<اسم-کتاب-به-انگلیسی-با-خط-تیره>-en.txt   # نسخه‌ی انگلیسی
```

## ساختار PDF خروجی

- **جلد:** قابِ طلاییِ دوخطی، نگینِ تزئینی، نام کتاب، یک جمله توضیح، لوگو و
  «Design by: @SaliSalvia»
- **فهرست:** بخش‌ها با عنوان، کپشن (در کتاب‌های کم‌بخش)، شماره‌ی صفحه‌ی متن و
  شماره‌ی تصویر؛ برای کتاب‌های پربخش، فهرستِ جمع‌وجورِ چندصفحه‌ای
- **صفحات متن:** عنوانِ بخش با خطِ طلایی در آغازِ هر بخش (بدونِ سرصفحه)، متنِ
  هم‌تراز با تورفتگیِ پاراگراف، فونتِ بزرگ و خوانا (Vazirmatn / EB Garamond)
- **سرصفحه‌ی صفحه‌های ادامه:** نامِ کتاب در صفحه‌ی سمتِ چپ و عنوانِ بخش در
  صفحه‌ی سمتِ راست
- **حاشیه‌ی آینه‌ای:** حاشیه‌ی شیرازه (inner) پهن‌تر از حاشیه‌ی بیرونی است و
  بین صفحه‌های زوج و فرد آینه می‌شود — آماده‌ی صحافی
- **شماره‌ی صفحه و ارقام:** در کتابِ فارسی با ارقامِ فارسی چاپ می‌شود
- **صفحه‌های تصویری:** تصویرِ تمام‌عرض + کپشنِ ادبی همان بخش
- **فوتر همه‌ی صفحات:** لوگوی کوچک + «Design by: @SaliSalvia» و شماره‌ی صفحه
- **پشت‌جلد:** توضیحِ نسخه، لوگو، نام و آدرس گیت‌هاب شما
- **داخل فایل PDF:** عنوان/نویسنده/موضوع/زبان در متادیتا، عنوانِ سند در نوارِ
  پنجره (`DisplayDocTitle`) و فهرستِ کنارِ PDF برای پرشِ سریع به هر بخش

نکته‌های کیفی: صفحه‌بندی روی مرزِ کلمه و با **شبیه‌سازیِ شکستنِ خط** انجام
می‌شود (نه تقسیمِ نویسه بر تعدادِ نویسه‌ی هر خط)، ارتفاعِ محتوای هر صفحه بعد از
ساخت اندازه‌گیری می‌شود و اگر صفحه‌ای سرریز کند با سقفِ کمتر دوباره چیده
می‌شود؛ فونت‌ها هم داخلِ `assets/fonts/` نگه داشته شده‌اند تا ساخت به شبکه
وابسته نباشد. ایتالیک‌های `_…_` متن‌های گوتنبرگ به `<em>` تبدیل می‌شوند تا
زیرخط‌ها در چاپ دیده نشوند.

## تست‌ها

کل خط تولید بدون هیچ کلید API و بدون شبکه قابل تست است (یک کلاینِ جعلیِ سازگار
با `google-genai` جایگزین مدل می‌شود):

```bash
pip install -r scripts/requirements.txt -r scripts/requirements-dev.txt
playwright install chromium
pytest                    # تست‌های آفلاین (unit + سرتاسری تا PDF)
pytest -m live            # تست‌های شبکه: گوتنبرگ/آرشیو/جست‌وجوی وب
```
