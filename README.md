## این ریپو چیست؟

یک خط تولیدِ کاملاً خودکار (GitHub Actions) که با گرفتنِ **فقط اسمِ یک کتاب**:

1. متن کتاب را پیدا می‌کند
2. در صورت نیاز، با Gemini یک ترجمه‌ی تازه‌ی فارسی از آن تولید می‌کند
3. متن را به بخش‌های تصویری تقسیم می‌کند (به‌طور متغیر، هر ۶ تا ۱۱ صفحه یک تصویر)
4. برای هر بخش پرامپت تصویری می‌نویسد و با Gemini تصویرسازی می‌کند
5. یک **PDF عمودی حرفه‌ای** با جلد، پشت‌جلد، فوتر برندشده و شماره صفحه می‌سازد

دو ورک‌فلوی جدا برای دو زبانِ خروجی وجود دارد:

| ورک‌فلو | فایل | زبان خروجی |
|---|---|---|
| 📖 Build Book — فارسی | `.github/workflows/build-book-fa.yml` | فارسی |
| 📖 Build Book — English | `.github/workflows/build-book-en.yml` | English |

نام کتاب را به هر زبانی که بدهید مهم نیست — مثلاً می‌توانید در ورک‌فلوی
انگلیسی اسم کتاب را فارسی تایپ کنید؛ Gemini آن را تشخیص و برای جست‌وجو
ترجمه می‌کند.

## راه‌اندازی

1. این ریپو را Fork/Clone کنید.
2. یک کلید API از [Google AI Studio](https://aistudio.google.com) بگیرید.
3. (پیشنهادی و امن‌تر) کلید را به‌صورت Repository Secret با نام
   `GEMINI_API_KEY` ذخیره کنید: `Settings → Secrets and variables → Actions`.
   یا به‌صورت جایگزین، همان لحظه‌ی اجرای اکشن در فیلد `gemini_api_key`
   واردش کنید (در لاگ‌ها ماسک می‌شود، ولی سکرت امن‌تر است).
4. به تب **Actions** بروید، ورک‌فلوی موردنظر (فارسی یا English) را انتخاب
   کنید، روی **Run workflow** بزنید، نام کتاب را وارد کنید و اجرا کنید.
5. بعد از پایان اجرا، فایل PDF در بخش **Artifacts** همان اجرا قابل دانلود است.

## اجرای محلی (اختیاری)

```bash
pip install -r scripts/requirements.txt
playwright install chromium

export GEMINI_API_KEY="کلید‌شما"
cd scripts
python generate_book.py --lang fa --title "شازده کوچولو" --api-key "$GEMINI_API_KEY" \
    --github-url "https://github.com/USERNAME/REPO"
```

## متن دلخواه خودتان

اگر می‌خواهید متنِ مشخصی مبنای کتاب باشد، کافی‌ست فایل آن را این‌جا قرار دهید
و دوباره اکشن را اجرا کنید — پردازش (تحلیل، تصویرسازی، PDF) از همان‌جا با
همان متن ادامه پیدا می‌کند:

```
manuscripts/<اسم-کتاب-به-انگلیسی-با-خط‌تیره>-fa.txt   # نسخه‌ی فارسی
manuscripts/<اسم-کتاب-به-انگلیسی-با-خط‌تیره>-en.txt   # نسخه‌ی انگلیسی
```

## ساختار PDF خروجی

- **صفحه‌ی اول (جلد):** نام کتاب، یک جمله توضیح، لوگو + «Design by: @SaliSalvia»
- **صفحات میانی:** بخش‌های متن (فونت بزرگ و خوانا) و صفحات نیمه‌تصویری،
  متناسب با طول کتاب (هر ۶ تا ۱۱ صفحه یک تصویر)
- **فوتر همه‌ی صفحات میانی:** گوشه‌ی پایین‌چپ لوگوی کوچک + «Design by: @SaliSalvia»،
  و شماره‌ی صفحه در وسط
- **صفحه‌ی آخر (پشت‌جلد):** توضیح کوتاه، لوگو، نام و آدرس گیت‌هاب شما
