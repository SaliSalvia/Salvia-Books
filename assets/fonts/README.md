# فونت‌های کتاب / Book fonts

این فایل‌ها نسخه‌ی محلیِ دو فونتِ خط تولید هستند تا ساختِ PDF هیچ‌وقت به
دسترسیِ شبکه به `fonts.googleapis.com` وابسته نباشد (اگر فونت لود نشود،
Chromium بی‌سروصدا فونتِ پیش‌فرض را می‌گذارد و کیفیتِ کتاب افت می‌کند).

| فونت | استفاده | مجوز |
|---|---|---|
| Vazirmatn | متن فارسی، عنوان‌ها | SIL Open Font License 1.1 |
| EB Garamond | متن و عنوان‌های انگلیسی | SIL Open Font License 1.1 |

فقط زیرمجموعه‌های لازم (عربی/فارسی، لاتین، لاتین گسترده) نگه داشته شده‌اند.
منبع: Google Fonts. برای به‌روزرسانی/بازتولید:

```bash
python scripts/fetch_fonts.py
```

`fonts.css` خروجی همان اسکریپت است (با نشانی‌های نسبی)؛ `render.py` هنگام
ساختِ HTML این نشانی‌ها را به `file://` مطلق تبدیل می‌کند.
